## Changes

- Hero: larger 660px desktop studio, bold two-line name, shared edges, a full-width two-column theme console. Mobile uses the same DOM with a compact title/role, 430px scene and stacked controls.
- Typography: display weight 650, section weight 550, improved heading/body scale, balanced headings and readable Korean paragraph spacing. Existing fonts and theme tokens remain in use.
- Archive: Projects, Post, Piece, Publications and About share the larger section-heading system. The existing large coverflow cards, content order and interactive behaviors remain intact.
- About: larger open-source statement and a quieter timeline separated by a rule. Contact: larger headline, divider and a directional hover response. Public detail titles share the revised weight.
- Reveal targets now sit on section headings rather than whole archive sections, preserving the backdrop for descendant glass controls and keeping long sections immediately available.
- Robot: existing licensed model and refined materials remain. Added entrance, theme-dependent body/left-arm pose, interpolated eye/core/rim colors, and subtle cursor-dependent key lighting. Reframed the camera to keep the hands in view.
- Fallback: regenerated `public/models/robot/poster.webp` from the actual final scene (80,208 bytes). Model provenance and licenses remain in `public/models/robot/`.
- All profile, project, research, publication, award and post data files remain unchanged.

## Motion contract

- Name: 900ms, second line delayed 100ms; theme word/heading: 650ms. Both use `cubic-bezier(.16, 1, .3, 1)` and backwards fill only.
- Robot entrance: 1.4s cubic ease-out, once per scene mount. Theme pose/color convergence uses `1 - exp(-7 * dt)`.
- Continuous scene motion stops when paused, offscreen, hidden or WebGL is lost. Reduced motion produces a static composed pose and disables text rolling. Explicit drag, zoom, theme selection and static scan/greeting remain available.
- Mobile keeps its existing lightweight GLB, 1.4 DPR cap and adaptive resolution. No additional renderer, postprocessing pass, library or 3D model download was added.
